Platform Acceleration & Weight Drag (2.1.21+)

space_platform_acceleration_expression = "(thrust / (1 + weight / 10000000) - ((90 * speed * speed) * ((weight / 200) ^ 0.80) + 10000) * sign(speed)) / weight / 60"

Setting acceleration to 0 yields equilibrium speed in km/s (60 × speed), where weight is in kg (tons × 1000) and thrust is in kN per tick-scale (102,000 = 102 MN for 1 Normal thruster at 80%+ fill). Orbital gravity shifts actual cruise speed by −10 km/s during the first half and +10 km/s during the second half of a trip.

Thruster Curve, Pumps & Hub Signals

min_performance = { fluid_volume = 0.1, fluid_usage = 0.1, effectivity = 1.00 } max_performance = { fluid_volume = 0.8, fluid_usage = 2.0, effectivity = 0.51 } thrust_kN = 100000 × quality × fluid_usage_per_tick × effectivity

Normal thruster usage interpolates linearly from 6 u/s (10% fill, 100% eff.) to 120 u/s (80% fill, 51% eff.), scaling by quality (1.0×, 1.3×, 1.6×, 1.9×, 2.5×). Base pump throughput is 1200 u/s (20 u/tick). Hub signals Read moving from (1) + Read moving to (2) sum to 3 while parked and < 3 while in transit.
